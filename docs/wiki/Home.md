# Vinilos · Wine Music

App Android nativa (Kotlin + Jetpack Compose) para consultar y administrar una colección de álbumes de vinilo sobre la API **BackVynils**. Proyecto del Equipo 10 para MISW4104 *Ingeniería de Software para Aplicaciones Móviles* (MISO, Uniandes).
